# Security Policy

## Supported Versions

Only the latest release of Shellumi Server is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Shellumi Server, please do **not** open a public issue.

Instead, please send an encrypted report or disclosure to the project maintainers via GitHub Private Vulnerability Reporting or via email to `security@shellumi.org` (or directly via the repository security advisory mechanism).

Please include:
- A description of the vulnerability and attack vector.
- Reproduction steps or proof of concept.
- An assessment of the impact.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
